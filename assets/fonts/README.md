Build-time fonts for Open Graph image generation (`manage.py generate_og_images`).

Not served to the browser — the site loads its webfonts from Google Fonts. These
are here so the OG images can be regenerated reproducibly on any machine.

Both are SIL Open Font License 1.1:
- Bodoni Moda — https://github.com/google/fonts/tree/main/ofl/bodonimoda
- Archivo — https://github.com/google/fonts/tree/main/ofl/archivo
