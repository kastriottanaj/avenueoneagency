Source fonts used for Open Graph image generation (`manage.py generate_og_images`)
and for the subsetted WOFF2 webfonts in `core/static/core/fonts/`. Browser fonts
are self-hosted so rendering does not depend on a third-party font request.

Both are SIL Open Font License 1.1:
- Bodoni Moda — https://github.com/google/fonts/tree/main/ofl/bodonimoda
- Archivo — https://github.com/google/fonts/tree/main/ofl/archivo
